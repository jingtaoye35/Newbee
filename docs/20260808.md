# Newbee 数据层说明 (2026-08-08)

## src/datasource 各层职责

1. **dataset.py** — 对外 (例如 backend) 提供统一读访问门面. backend MUST 只 import 这个.
2. **cli.py** — 更新本地数据文件 (`datas status` / `datas update` / `datas init-universe` 等).
3. **schema/*.py** — 定义本地数据文件的 Pydantic schema (字段 + ClassVar 元信息).
4. **adapter/*.py** — 从外部数据源 (akshare / baostock / finance) 获取数据.
5. **service/*.py** — 从 adapter/*.py 拉数据, 转换成本地格式, 落盘. 提供 full_init / daily_update.
6. **storage/*.py** — IO 封装 (DataFile parquet/CSV 读写, bars_adapter 矩阵化 K 线, pool_adapter 股票池).

## M1-completion 变更摘要 (datasource-m1-completion)

**变更范围:** 数据层机械性整理, 不引入新功能, 只打通已有的 M1 骨架.

### 关键变更

1. **删除 `registry.py`** — `DataType` 是 Pydantic ClassVar 的纯转发层, 单例 `REGISTRY` 仅服务 1 处 CLI 用途. 全部替换为直接 `from datasource.schema.X import Class` + `DataFile(Class)`.
2. **`DataFile` 新签名** — `DataFile(model, *, root=None, storage_path_override=None)`. `storage_path_override` 消除了 pool_adapter / cli migrate 里的 `dc_replace(dtype, ...)` 绕路.
3. **12 处 import 路径修复** — `datasource.sources.*` 不存在, 全部改 `datasource.adapter.*`.
4. **`schema/stock_kdata.py` 类名修复** — 真实类名 `StockKData`, 在 `schema/__init__.py` 用 `as Stock_KData` 别名导出, 保留 `type_name` ClassVar 的 `Stock_KData` 命名.
5. **新增 `schema/trade_status.py`** — `TradeStatus(trade_date, stock_code, is_suspended, is_st, is_activate)`.
6. **新建 `dataset.py` facade** — 8 个 loader, backend 走这里. 含 `load_kdata → Bars`, `load_universe → StockPool`, `load_stock_basic_data / load_trade_status / load_dividend_history / load_financial_report / load_financial_indicator → DataFrame`, `load_trade_calendar → list[date]`.
7. **`backend/strategy/watchlist/pipeline.py` 同步** — 从 `REGISTRY.get(name).storage_path` 改为 `SCHEMAS[name].storage_path` (因为 REGISTRY 已删).
